# AI Usage

## Tools Used

- ChatGPT (Free Version)

I intentionally used the free version because I wanted AI to assist me during the development process without relying on more powerful tools that could do a larger part of the implementation for me. The goal was to use AI as a development assistant while still being responsible for the implementation and decisions throughout the assignment.

## How AI Was Used

AI was mainly used as a development assistant for:

- Exploring different implementation approaches
- Discussing architecture and code organization
- Reviewing code and identifying potential issues
- Debugging and troubleshooting
- Getting feedback on implementation decisions

## Developer Responsibility

AI suggestions were reviewed, adapted and tested before being used in the project. I did not blindly copy generated solutions and made the final decisions about the architecture, implementation and trade-offs myself.

The final implementation was written, integrated and verified by me.
